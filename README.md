## SkeySpot Application Overview
This git file is an official repository of the work titled "SkeySpot: Automating Service Key Detection for Digital Electrical Layout Plans in the Construction Industry", accepted at IEEE SMC 2025, authored by Dhruv Dosi, Rohit Meena, Param Rajpura, and Yogesh Kumar Meena. The app provides an intuitive interface to upload scanned layout plans, perform real-time detection of electrical service key symbols using a YOLOv8-based model, and visualize the results with bounding boxes and class-wise counts. It supports both single and batch image processing modes, allowing users to download annotated outputs and generate symbol-wise cost estimations.

You can visit the app at: [https://skeyspot.streamlit.app/](https://skeyspot.streamlit.app/)

The dataset used for training and evaluation will be made available for academic research upon request to the authors.
